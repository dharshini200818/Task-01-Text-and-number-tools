Task 01 — Text and number tools
This project is a Python program that performs basic operations on a sentence read from the user and checks whether a given number is prime.

The program has the following functions: 
1. word_count() which counts the number of words in the sentence.
2. longest_word() which finds the longest word in the sentence.
3. reverse() which reverses the sentence.
4. prime_check() which checks whether an integer is prime, composite, or neither.

Software used : Python 3.12.3

Each of these functions does one specific task. A common input is read from the user for the sentence-based task andd a seperate input is read for the prime number check task. Appropriate labelled output is displayed on execution.
Execution : 
Open the project folder in a terminal and run:
python3 task_1.py
